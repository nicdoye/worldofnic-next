I did a lot of open source in the late 1990s and early 2000s — code in released versions of [Pure-FTPd](https://www.pureftpd.org/project/pure-ftpd/), [GNU Privacy Guard](https://www.gnupg.org), and the official [Exim](https://exim.org/) RPM spec, plus patches for [Cyrus-SASL](https://www.cyrusimap.org/sasl/) and [mod_auth_mysql](https://modauthmysql.sourceforge.net), alongside assorted Perl, JavaScript and RPM packaging.

I’ve added trivial amounts of code to the [Kubernetes](https://kubernetes.io) autoscaler, [Helm](https://helm.sh), [Hugo](https://gohugo.io) and more.

I’ve often thought about writing a DNS server. It’s never happened, but there’s [a sketch of the design](https://nicdoye.github.io/andns/).
